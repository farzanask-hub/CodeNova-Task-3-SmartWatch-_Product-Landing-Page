# VYRA One — Smartwatch Product Landing Page

A modern, responsive smartwatch landing page created for **CodeNova Batch 01 Frontend Development Internship — Task 3**.

## Features
- Premium hero section with a CSS smartwatch illustration
- Responsive navigation with an accessible mobile menu
- Feature cards for daily insights, focus, and connectivity
- Product design story and specifications section
- Call-to-action button with interactive feedback
- Mobile, tablet, and desktop responsive layouts
- Semantic HTML and reduced-motion support

## Technologies
- HTML5
- CSS3 (Flexbox, Grid, gradients, media queries)
- Vanilla JavaScript

## Project files
- `index.html` — page structure and content
- `style.css` — design, CSS watch illustrations, and responsive styling
- `script.js` — mobile navigation and CTA interaction

## Run locally
Open `index.html` in a modern browser. No backend, API, or external data files are required. An internet connection is only needed for optional Google Fonts.

## Deploy with GitHub Pages
1. Create a public GitHub repository.
2. Upload `index.html`, `style.css`, `script.js`, and `README.md` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main` and folder `/(root)`, then save.
6. Wait for deployment and open the URL shown in Pages settings.

## Customize
VYRA One is a fictional product concept for this student project. Edit the product copy, colors, and concept price in `index.html` and `style.css`. The CTA only displays an informational message; it does not process orders or payments. Feature descriptions are illustrative and are not verified product specifications.
